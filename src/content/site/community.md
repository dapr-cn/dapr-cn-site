## 加入 Dapr Discord

如果需要了解构建块 API 或生产运行方面的帮助，Discord 是向社区、贡献者和维护者求助的最佳去处。如果你已经熟悉 Dapr，也欢迎回答问题，帮助其他用户。

[前往 Dapr Discord](https://diagrid.ws/dapr-discord)

## 成为 Dapr Meteor

Dapr Meteors 是一群通过帮助他人、创作内容和贡献项目，对社区产生重要影响的 Dapr 爱好者。如果你热爱 Dapr 且积极参与社区，可以考虑自荐。

[了解 Dapr Meteors 计划](/community/program/)

## 参加社区会议

Dapr 每月在 [YouTube](https://www.youtube.com/@daprdev/streams) 直播社区会议，邀请维护者、贡献者、最终用户与社区成员分享新功能和经验。这是提问、向同行学习的好机会。想在会议中演讲，可以在 GitHub 上的[社区会议议题](https://github.com/dapr/community/issues?q=is%3Aissue+is%3Aopen+label%3A%22community+call%22)中留言。

[观看社区会议](https://www.youtube.com/@daprdev/streams)

## 做一场 Dapr 分享

许多爱好者在本地聚会、全球大会或工作单位分享 Dapr。项目提供完整的 PowerPoint 演示文稿，你可以以此为起点，根据需要修改。到文档站下载幻灯片，完成分享后即可申请 [Dapr 演讲者徽章](https://github.com/dapr/community/tree/master/presentations)。

[下载演示文稿](https://docs.dapr.io/contributing/presentations/)

## 收集 Dapr 徽章

代码、文档、演讲和博客贡献都可以获得数字 [Dapr 徽章](https://www.holopin.io/@dapr)。代码贡献通过普通拉取请求授予徽章，[作者](https://github.com/dapr/community/tree/master/blogposts)与[演讲者](https://github.com/dapr/community/tree/master/presentations)徽章通过社区仓库授予。现在就可以领取[社区支持者徽章](https://bit.ly/dapr-supporter)，也欢迎在社交媒体分享。

## 为 Dapr 做贡献

Dapr 完全开源，是 [CNCF](https://www.cncf.io/projects/dapr/) 的项目。社区欢迎网站改进、文档完善、缺陷修复和新功能等各类贡献。有兴趣参与，请查看 GitHub 组织与[贡献指南](https://docs.dapr.io/contributing/)。

[访问 Dapr GitHub 组织](https://www.github.com/dapr)
