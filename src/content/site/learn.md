## 核心概念

通过文档了解 Dapr 运行时、构建块 API、组件，以及开箱即用的跨领域能力。

[学习 Dapr 核心概念](https://docs.dapr.io/concepts/)

## 开始使用

按照入门指南在本地安装 Dapr，并通过状态管理 API 与 Dapr Sidecar（边车）交互。

[开始使用 Dapr](https://docs.dapr.io/getting-started/)

## 快速入门

在本地运行 Dapr 应用，体验不同的构建块 API。示例提供 .NET、Java、Python、JavaScript 和 Go 等语言版本。

[体验 Dapr 快速入门](https://docs.dapr.io/getting-started/quickstarts/)

## Dapr Dev Dashboard

开发时查看 Dapr 在本机的运行情况。Dapr Dev Dashboard 实时展示应用、Sidecar、组件和工作流执行，还提供组件文件和弹性策略的引导式配置工具。它由 Diagrid 维护，可以免费使用。

[体验 Dapr Dev Dashboard](https://docs.diagrid.io/dapr-open-source/dapr-dev-dashboard/)

## Dapr University

免费的自主学习项目，提供动手实践课程。课程使用云端沙箱，无需本地配置，只需要浏览器。Dapr University 由 Diagrid 为社区赞助。

[参加 Dapr University 课程](https://www.diagrid.io/dapr-university)

## Dapr YouTube 频道

观看使用案例、会议演讲和定期社区会议。

[在 YouTube 上探索 Dapr](https://www.youtube.com/daprdev)
