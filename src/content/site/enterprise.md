## Dapr Support

Diagrid 的 [Dapr Support](https://www.diagrid.io/dapr-support) 由 Dapr 的创建工程师提供，为任意云上未经修改的开源 Dapr 提供商业支持。

Dapr Support Pro 面向开发阶段的团队，价格为每月 99 美元，提供不限数量的邮件工单，覆盖美国和欧洲工作时间。Enterprise Dapr Support 面向关键生产系统，提供全天候支持，承诺关键生产问题一小时响应，还包含 D3E 支持、CVE 修补、架构设计评审和 Dapr 功能优先级安排。两个方案均包含十小时结构化入门指导。

Diagrid 还提供免费的 [Dapr Ops Dashboard](https://www.diagrid.io/dapr-ops-dashboard)（原 Diagrid Conductor）。这一 SaaS 工具自动管理 Kubernetes 上的 Dapr 运维，包括安装、升级、mTLS 证书轮换以及跨集群可视化。

## Diagrid Dapr Distribution for Enterprise（D3E）

[D3E](https://docs.diagrid.io/dapr-open-source/d3e/) 是面向受监管、多租户及权限受限 Kubernetes 环境的开源 Dapr 定制发行版。它通过命名空间级安装和每集群多个控制平面支持多租户，缩小 RBAC 权限范围，并向定制版本回移 CVE 修复，同时保持与开源 Dapr API 和 SDK 的 100% 兼容。D3E 可作为 Enterprise Dapr Support 的附加服务购买。

## Diagrid

[Diagrid](https://www.diagrid.io/catalyst) 是面向 AI 代理、工作流、MCP server 和应用的持久化执行平台。它提供持久化执行、可验证执行，以及基于策略访问的密码学身份，无需在应用中编写可靠性或安全代码。

代理和工作流能够在崩溃、部署和重启后自动恢复，从停止处继续；执行过程可以得到证明，每次调用都会经过策略检查。它兼容 Dapr Agents、CrewAI、LangGraph、Strands、OpenAI Agents、Google ADK、Pydantic AI、Microsoft Agent Framework、Mastra 和 Claude Agents 等框架。

Diagrid 不执行你的应用或代理代码：应用可以运行在你选择的位置，通过 API 调用 Diagrid。平台基于开源 Dapr，提供 Diagrid Cloud、Dedicated Cloud、BYOC（托管或自行管理）及 Enterprise Server。Enterprise Server 完全运行在自有基础设施上，也可以部署在物理隔离网络中。

[访问 Diagrid](https://www.diagrid.io)

## Azure Container Apps

Azure Container Apps 是基于 Kubernetes 的全托管应用平台，可以从代码或容器部署应用，无需编排复杂基础设施。集中统一的网络、可观测性、动态扩缩容和配置能力，有助于提高异构现代应用与微服务的开发效率。平台完整支持 Dapr，并通过 KEDA 动态扩缩容，帮助构建具有弹性的微服务。

[访问 Azure Container Apps](https://azure.microsoft.com/en-us/products/container-apps/)

## Intent Architect

选择架构、技术与编码规范，快速编写下一个 .NET 应用。这个新一代平台让你按照自己的方式控制架构，在不牺牲代码库控制权和可定制性的前提下，大幅提高开发效率、一致性与准确性。

[访问 Intent Architect](https://intentarchitect.com/)
